# Trivia

The best facts about GW Evolution, each with its source.

- All four commits landed on the same day, 2025-08-13, from the first take
  (`29a2dc4`) to "we got some stuff working" (`82c58af`).
- The biggest commit, 4,667 lines across 28 files, built the entire
  React/three.js scene — camera, lighting, hex tiles, spec cards and
  postprocessing — in one commit (`84eb060`).
- A five-stage migration plan (`docs/executionplan.md`, Day 0 through
  Day 4) laid out building the 3D scene over several days; every commit it
  describes landed within the same single day (`29a2dc4`, `82c58af`).
- The class tree (`evolist.txt`) holds six base classes — Priest, Druid,
  Mesmer, Warrior, Mage, Rogue — each with three specializations,
  eighteen in all (`29a2dc4`).
