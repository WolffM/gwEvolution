# History

One era: GW Evolution never left its first day.

## A single day, two apps (2025-08-13)

Every commit in the repo landed on 2025-08-13: the first take at the Dash
prototype (`29a2dc4`), a 4,667-line commit that built the entire
React/three.js scene — camera, lighting, hex tiles, spec cards and
postprocessing — in one go (`84eb060`), a tile-bobbing animation pass
(`401e020`), and the last commit, "we got some stuff working" (`82c58af`).
The repo has had no commits since.

The Dash app in `app.py` came first and is the "legacy" option the README
still documents; the React/three.js scene in `gw-evolution-r3f/` is the one
the README recommends running.

## Trivia

The repo's own migration plan (`docs/executionplan.md`) is written as a
five-day plan, Day 0 through Day 4; the whole thing happened in one day
instead (`29a2dc4`, `82c58af`).
